# Fallback benchmarks

Use these only when the user doesn't have their own data. Always label them as assumptions in the plan. Your own history beats any benchmark. These are rough working ranges for venture-backed, mid-market B2B SaaS, not research findings. Check current sources (for example Kyle Poyar's Growth Unhinged, public SaaS benchmark reports, or your investors' portfolio data) before using them in a board deck.

| Metric | Rough working range | Notes |
|---|---|---|
| Starting pipeline coverage | 2.5x to 4x of the quarter's new bookings | Set from your own history. See `capacity-and-pipeline.md`. |
| Pipe/spend (demand gen) | 8:1 to 20:1 | Pipeline dollars created per demand gen program dollar. |
| AE ramp | 2 to 3 quarters (mid-market), 3 to 4 (enterprise) | |
| Ramped AE productivity | 4x to 6x of on-target earnings per year | Varies widely by ACV. |
| Gross revenue retention | 85% to 92% | |
| Net revenue retention | 100% to 115% | |
| CAC ratio (S&M spend / new ARR) | 1.0 to 2.0 | Lower is better. |
| Marketing share of S&M | 30% to 45% | |
| Experiments share of programs | 10% to 20% | Common rule of thumb. |
| Strategic programs share | 55% to 75% | Common rule of thumb. |

If a user's number sits far outside a range, ask about it. It may be fine, but it's worth one question.
